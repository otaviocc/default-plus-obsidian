# Default+

A dark color theme for Obsidian, originally created as an Xcode Font & Color Theme.

Part of the [Default+ theme family](https://github.com/otaviocc/default-plus).

## Installation

### Community Themes (recommended)

1. Open Obsidian Settings
2. Go to **Appearance**
3. Click **Manage** next to Themes
4. Search for **Default+** and click **Install and use**

### Manual installation

1. Download `theme.css` and `manifest.json` from this repository
2. Copy both files to `<vault>/.obsidian/themes/Default+/`
3. Open Obsidian Settings → **Appearance** → select **Default+** under Themes
